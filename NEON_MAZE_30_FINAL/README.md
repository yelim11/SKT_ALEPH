# NEON MAZE 30 — 최종 과제 패키지

## 게임 개요
고전 미로 추적 게임을 오마주한 30초 미니게임입니다. 28×36 타일 미로에서 코인을 모으고 서로 다른 타겟 규칙을 가진 유령 4마리를 피합니다. 파워 코인을 먹으면 유령이 잠시 Frightened 상태가 되어 먹을 수 있습니다.

## 실행
1. 이 폴더를 그대로 GitHub Pages 같은 정적 호스팅에 업로드합니다.
2. `index.html`을 엽니다.
3. 로그인, 서버, API 키, 외부 음원 다운로드, 빌드 과정이 필요 없습니다.

## 조작
- 방향키 또는 WASD를 누르고 있는 동안만 연속 이동합니다.
- 키를 떼면 즉시 멈춥니다.
- 1타일 폭의 좁은 직선 통로에서는 길 중심선에 정렬되어 직진/후진합니다.
- 교차로·코너·넓은 공간에서는 상하좌우 방향 전환이 가능합니다.
- `P` 또는 일시정지 버튼으로 멈췄다가 이어서 할 수 있습니다.

## 코인 배치
- 새 판마다 랜덤 시드를 새로 만들어 코인 위치가 달라집니다.
- 코인은 벽, 유령 집, 시작 지점을 피하고 이동 가능한 통로 타일의 정확한 중앙에만 생성됩니다.
- 판 기록에는 사용한 `pelletSeed`도 남아 재현/비교 자료로 활용할 수 있습니다.

## 유령 AI
- RUBY: 플레이어 현재 타일 추적
- ROSE: 진행 방향 4타일 앞 타겟
- CYAN: 진행 방향 앞 2칸과 RUBY 위치를 이용한 벡터 타겟
- AMBER: 8타일보다 멀면 추적, 가까우면 왼쪽 아래 코너로 후퇴

공통 규칙은 벽과 즉시 역방향을 제외한 후보 중 타겟과 제곱거리가 가장 짧은 다음 타일을 선택하고, 동률이면 UP > LEFT > DOWN > RIGHT 순입니다. Frightened에서는 가능한 방향 중 무작위로 고릅니다.

## 이동/충돌 안정화
- 키 반복 이벤트와 실제 이동을 분리해 키를 오래 눌러도 중간에 멈추지 않습니다.
- 플레이어와 유령의 이동을 작은 구간으로 나누어 원형 충돌 판정을 하므로 빠르게 움직여도 벽을 건너뛰지 않습니다.
- 좁은 직선 통로에서는 중심선에 정렬됩니다.
- 좌우 터널에서는 유령을 통로 중앙에 유지하고 반대편 정상 타일로 복귀시켜 터널에 끼는 문제를 방지합니다.

## 화면 효과와 사운드
- 성공 시에만 폭죽 효과가 실행됩니다.
- `효과 줄이기`를 켜면 폭죽·충돌 플래시 같은 움직임 효과가 즉시 멈춥니다.
- BGM과 코인/파워/충돌/유령 먹기/성공/실패 효과음은 외부 음원이 아니라 Web Audio API로 직접 생성합니다.
- `소리 끄기`를 켜면 BGM과 효과음이 즉시 음소거됩니다.

## 저장
브라우저 `localStorage`에 아래 보존값을 저장합니다.
- 최고 점수
- 최고 클리어 시간
- 총 완료 플레이 횟수
- 총 실제 플레이 시간(일시정지 시간 제외)
- 효과 줄이기 설정
- 소리 끄기 설정

현재 판의 위치, 남은 시간, 목숨, 점수, 코인 상태, 유령 상태는 저장하지 않으며 새 판에서 초기화됩니다.

저장은 서버나 IP를 사용하지 않으므로 다른 컴퓨터/브라우저의 기록과 섞이지 않습니다. 같은 컴퓨터에서도 브라우저나 브라우저 프로필이 다르면 별도 저장소가 사용될 수 있습니다.

검사 기록 도구의 버튼:
- `저장하기`: C23 보존값 저장 확인
- `저장 초기화`: C24 빈 저장값 기본 복구 확인
- `손상값 테스트`: C25 깨진 JSON 안전 복구 확인

## 과제 조건 대응
- C01: 정적 파일만 사용하며 로그인/인증이 필요 없습니다. 실제 배포 뒤 시크릿 창에서 URL을 확인하세요.
- C03~C05: 규칙, 조작, 상태를 공개 화면에 표시합니다.
- C06/C12: 각 방향 keydown 이벤트를 입력/의도 카운터에 한 번씩 반영하며 실제 이동은 held-key 상태로 연속 처리합니다.
- C07: 모든 코인을 먹으면 성공, 목숨 소진 또는 30초 초과 시 실패합니다.
- C08/C09/C22: 재시작 시 현재 판 값을 초기화합니다.
- C10/C11: 1366×768과 1920×1080에서 게임 캔버스가 화면에 들어오고 가로 넘침이 없도록 반응형 크기를 적용했습니다.
- C13: 창 크기 변경은 게임 논리 상태를 변경하지 않습니다.
- C14/C15: 포커스 이탈 시 자동 일시정지하고 복귀 뒤 기준 시각을 다시 맞춥니다. 수동 일시정지도 지원합니다.
- C16/C17: 단일 requestAnimationFrame 루프와 고정 이벤트 리스너 구조입니다. 제출 전 실제 10분 실행/콘솔 검사는 직접 완료하세요.
- C18~C21: `GHOST_SPEED` 하나만 바꾸고 10회+10회 기록을 비교합니다. 랜덤 코인 생성 규칙 자체는 두 설정에서 동일하게 유지합니다.
- C23~C25: 보존 저장, 빈 저장 기본값, 손상 저장 복구 기능이 있습니다.
- C26: 폭죽은 성공 사건에서만 실행됩니다.
- C27: 효과 줄이기를 켜면 폭죽/플래시가 즉시 중단됩니다. 소리 끄기도 즉시 적용됩니다.
- C28/C29: IP·개인정보·API 키·비밀값을 수집/사용하지 않습니다.

## 난이도 20회 비교
`game.js` 상단의 `GHOST_SPEED`만 변경합니다. 예시는 72와 82입니다.

1. `GHOST_SPEED = 72` 상태로 직접 10판 플레이합니다.
2. 다른 설정은 건드리지 않고 `GHOST_SPEED = 82`로만 바꿉니다.
3. 다시 직접 10판 플레이합니다.
4. 검사 기록 도구의 최근 20회 결과에서 성공/실패, 점수, 생존시간, 실패 원인을 비교해 최종 속도를 고릅니다.

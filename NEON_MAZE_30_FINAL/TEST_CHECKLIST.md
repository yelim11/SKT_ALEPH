# PC 경계 및 완주 검사표

## 해상도
- [ ] 1366×768: 게임 조작 영역 잘림 0 / 가로 넘침 0
- [ ] 1920×1080: 게임 조작 영역 잘림 0 / 가로 넘침 0

## 입력/상태
- [ ] 방향키/WASD를 계속 누르면 중간에 멈추지 않고 연속 이동
- [ ] 키를 떼면 즉시 정지
- [ ] 벽을 통과하지 않음
- [ ] 좁은 통로에서는 중심선 유지, 교차로/넓은 공간에서는 방향 전환 가능
- [ ] 유령이 좌우 터널을 지나도 벽/통로에 끼지 않음
- [ ] 1초 안에 같은 방향 keydown 이벤트 10건 → 입력 이벤트 수/방향 의도 반영 수가 각각 10 증가
- [ ] 창 크기 변경 뒤 게임 상태/조작 유지
- [ ] 다른 탭/창으로 포커스 이탈 시 일시정지, 복귀 뒤 이어짐
- [ ] P 또는 버튼 일시정지 중 시간/유령/플레이어/총 플레이 시간이 진행되지 않음

## 코인
- [ ] 새 판에서 코인 위치가 달라질 수 있음
- [ ] 모든 코인이 통로 타일 중앙에 있고 벽/유령 집에 생성되지 않음

## 10분
- [ ] 실제 10분 연속 실행 뒤 방향키 조작 가능
- [ ] 개발자도구 Console 빨간 오류 0건

## 저장
- [ ] 새 게임 시 시간/목숨/점수/위치/코인/유령 상태 초기화
- [ ] 저장하기 → 새로고침 후 최고점수/총 플레이/총 플레이 시간/효과 설정/음소거 설정 유지
- [ ] 저장 초기화 → 빈 저장값에서 기본값으로 정상 시작
- [ ] 손상값 테스트 → 깨진 저장값을 기본값으로 복구하고 게임 정상
- [ ] 다른 컴퓨터의 기록을 구분하기 위해 IP/개인정보를 사용하지 않음

## 효과/사운드
- [ ] 성공에서만 폭죽 실행
- [ ] 효과 줄이기 ON → 폭죽/충돌 플래시 즉시 중단
- [ ] 게임 시작 후 BGM 재생
- [ ] 코인/파워/충돌/성공/실패 효과음 동작
- [ ] 소리 끄기 ON → BGM/효과음 즉시 음소거

## 난이도 20회 기록
- [ ] 변경 전 `GHOST_SPEED` 한 값으로 직접 10회
- [ ] `GHOST_SPEED` 하나만 변경
- [ ] 변경 후 같은 나머지 설정으로 직접 10회
- [ ] 결과 범위/중앙값 또는 반복 실패 원인과 연결해 최종값 선택
